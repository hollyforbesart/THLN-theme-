## Old Grocery Guide link → new one

Old: `https://thehairlossnutritionist.com/hair-growth-grocery-guide/`
New: `https://roots.thehairlossnutritionist.com/products/grocery-guide`

- [ ] **Redirect the old address.** Add a 301 redirect from `/hair-growth-grocery-guide/` to the new link, so old bookmarks, Pinterest pins and emails still land on the guide. In WordPress, the free **Redirection** plugin does this: Tools → Redirection → Add new, with Source URL `/hair-growth-grocery-guide/`, Target URL the new link, and type 301. If the old page still exists, set it to Draft first, or WordPress will keep showing it.
- [ ] **Blog posts.** Replace the old link wherever a post mentions it. The free **Better Search Replace** plugin can find every post that contains `hair-growth-grocery-guide`: run it as a "dry run" first to see the count, then for real. Back up first (UpdraftPlus). The redirect catches any you miss, but direct links are faster and cleaner.
- [ ] **Resources page.** Resources → Hair Growth Grocery Guide: update the link, title, price and description to match the revamp.
- [ ] **Anywhere else:** Kit emails and sequences, link-in-bio, Pinterest pins, other PDFs.
- [ ] Test: open the old address in a private window and check it lands on the new guide.
